## Purpose

Track the architecture and design system diagrams, editable sources, and image review for the SuperPlane documentation contribution.

The upstream repository already has an architecture guide and frontend guidance. The new work adds visual maps and corrects outdated descriptions.
The review did not find a dedicated open issue or an equivalent open documentation PR.

## Materials

- [Artifact branch](https://github.com/velrino/superplane/tree/artifacts/architecture/architecture): research, review notes, renderer, symbols, and final images.
- [Python renderer](https://github.com/velrino/superplane/blob/artifacts/architecture/architecture/source/architecture_graphviz.py).
- [Symbols](https://github.com/velrino/superplane/tree/artifacts/architecture/architecture/source/symbols): all icons in one folder.
- [PNG output](https://github.com/velrino/superplane/tree/artifacts/architecture/architecture/source/output): two 3840 × 2160 images; no SVG output.
- [Documentation branch](https://github.com/velrino/superplane/tree/docs/architecture-overview/docs/architecture): the proposed upstream documentation and PNGs.

The documentation branch starts from upstream main at `bfb220601dae150e1f635a840ac597c0d6ad669d`.
It excludes the pending Notion and task-log contributions.
The artifact branch has independent history and will not be used as an upstream PR head.
